# Twenty or more linux commands

# File management commands

* cd:- to change directory
* pwd:- to show the path of the current running directory
* mkdir:- to make a new directory
* cp:- to copy file or a directory
* mv:- to move a file or directory in another file or directory
* rmdir:- to remove a directory permanently

# File Transfer/SSH Commands

* ssh user@access:- to securely log into and manage a remote computer or server over an unsecured network
* ssh access:- Connect to access as local username

# File Permission Commands

* chmod -rwx [file]:- give permission to the user/group/others to read, write, and execute
* chown user [file]:- to change the ownership of a file
* chgrp group [file]:- to change the group of file

# Process Commands 

* ps:- to show process status
* top:- to show important information of process
* kill processID:- used to kill process by its id
* vmstat:- to display status of virtual memory

# Networking Commands

* ifconfig:- to display network interfaces with ip addresses
* ping:- check the server
* dig domain:- to display DNS for domain

# System Information Commands

* uname:- shows linux system information
* sudo:- (super user do) giving root access to the user
* shutdown:- to shutdown the system
* reboot:- restarts the system
